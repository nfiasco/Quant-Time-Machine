# Quant Time Machine — Frontend

The Quant Time Machine web app, built with [Next.js](https://nextjs.org) (App Router), React, TypeScript, and [Tailwind CSS](https://tailwindcss.com). It was bootstrapped with the official [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) starter.

## Getting started

Requires Node.js 20.9+ (24 LTS recommended; see [`../.nvmrc`](../.nvmrc)).

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Pages auto-update as you edit files.

## Scripts

| Command         | What it does                                          |
| --------------- | ----------------------------------------------------- |
| `npm run dev`   | Start the dev server on port 3000                     |
| `npm run build` | Production build (also type-checks the project)       |
| `npm run start` | Serve the production build (run `build` first)        |
| `npm run lint`  | Lint with ESLint                                      |

## Project structure

```
app/
├── layout.tsx    # Root layout: <html>, fonts (Geist), page metadata
├── page.tsx      # Homepage (/)
├── globals.css   # Global styles and Tailwind CSS import
└── favicon.ico
```

New routes are folders inside `app/` with a `page.tsx` (for example, `app/backtests/page.tsx` → `/backtests`). Static files like images go in a `public/` folder (create it when needed).

`AGENTS.md` and `CLAUDE.md` were generated by `create-next-app`. They point AI coding assistants to the Next.js docs bundled in `node_modules/next/dist/docs/`, which match the installed version. `next dev` re-adds them if they are removed, so keep them committed.

## Deployment (Vercel)

1. In Vercel, choose **Add New → Project** and import this GitHub repository.
2. Set **Root Directory** to `frontend`. Vercel detects Next.js automatically, so no `vercel.json` is needed.
3. Deploy. Every pull request then gets its own preview URL.
