# Getting help

Start with the [project README](README.md), [frontend guide](frontend/README.md), and [backend guide](backend/README.md). The [roadmap](doc/roadmap.md) identifies planned features; an unfinished page is not evidence that its backend capability exists.

| Need | Where to go |
| --- | --- |
| Setup, usage, or point-in-time methodology question | [Discussions: Q&A](https://github.com/nfiasco/Quant-Time-Machine/discussions/categories/q-a) |
| Feature proposal or design tradeoff | [Discussions: Ideas](https://github.com/nfiasco/Quant-Time-Machine/discussions/categories/ideas) |
| Reproducible defect or agreed work | [Issue forms](https://github.com/nfiasco/Quant-Time-Machine/issues/new/choose) |
| Accessibility barrier | [Accessibility reporting](ACCESSIBILITY.md#report-an-accessibility-barrier) |
| Suspected vulnerability | [Private security reporting](SECURITY.md#report-a-vulnerability-privately) |
| Community behavior concern | [Code of Conduct reporting](CODE_OF_CONDUCT.md#enforcement) |

Include the relevant commit, route or command, expected behavior, and a small reproduction. Use synthetic examples and redact credentials, personal information, and restricted data. Maintainers and community members respond as time allows; this project has no commercial support service.
